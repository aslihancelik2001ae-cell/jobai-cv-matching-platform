# Job Posting & CV Matching Platform

An academic project exploring an AI-assisted web platform for matching CVs with job postings and helping employers evaluate candidates. The project combines UI/UX design, requirements engineering, Agile/Scrum project management, AI/NLP matching concepts, testing, and project planning.

> **Portfolio note:** This repository contains the project documentation, planning artifacts, UI/UX mockups, and test scenarios available in the submitted project archive. The submitted archive did **not** contain the application source code or backend/AI implementation files, so this repository does not claim to be a complete production implementation.

## Project Goals
- Help job seekers upload CVs and discover relevant job opportunities.
- Help employers publish jobs and evaluate candidates.
- Explore semantic/AI-assisted CV-to-job matching and explainable match scores.
- Design a clear and responsive user experience for both user types.

## Key Features Designed
- Candidate authentication and profile management
- CV upload and AI-assisted skill extraction
- Job search, filtering, and personalized recommendations
- Application history and status tracking
- Employer job-post creation
- AI-assisted candidate evaluation
- Candidate talent database
- Company profile management

## AI / Matching Concept
The requirements describe a hybrid matching approach combining keyword search and semantic embeddings. The proposed scoring model allocates weight to hard skills, experience, soft skills, and education, with explainability intended to show users why a match was recommended.

## Methodology
The project follows an Agile Scrum approach with short sprints, backlog management, sprint reviews, testing, and retrospectives. Project scheduling also uses WBS, PERT, Gantt Chart, and Critical Path Analysis.

## Project Planning
The documented schedule covers an 8-week academic timeline. The documented critical path is:

`Initiation → UI/UX Design → Frontend Development → Integration → Documentation`

The project analysis estimates approximately 9.2 weeks for the critical path, creating a schedule risk against the 8-week academic deadline.
